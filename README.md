## 🌟 About This Repository

**Nafij Resources** is a curated collection of useful digital resources gathered to help people learn new skills, discover valuable tools, explore technology, and build better projects.

Created by **[Nafij Rahaman](https://github.com/nafijrahaman)**, a full-stack developer and technology enthusiast from Bangladesh, this repository aims to make useful resources easier to discover and access.

Whether you're a student, beginner developer, experienced programmer, designer, creator, or tech enthusiast, you'll find a growing collection of resources worth exploring.

The repository may include both **free resources and paid resources**. Paid resources will be identified where applicable, and their original sources or purchase links will be provided whenever possible.

## 💎 Free & Paid Resources

Resources are shared with clear distinctions whenever their pricing is known.

- 🟢 **Free:** Available at no cost under the stated terms.
- 🔵 **Freemium:** Offers free features with optional paid upgrades.
- 🟠 **Paid:** Requires a purchase or subscription.
- 🟣 **Open Source:** Source code is available under the project's specified license.

**Please note:** Pricing, availability, licensing, and promotional offers can change. Always verify the details on the original website before downloading, purchasing, or using a resource.

## 🚀 How to Use This Repository

1. **Explore** the repository to discover available resources.
2. **Choose** a category relevant to your needs.
3. **Check** the resource description, pricing, and licensing information.
4. **Visit** the original source using the provided link.
5. **Learn, create, and build** something useful with what you discover.

## 🤝 Contributing

Have a useful website, tool, course, template, open-source project, or other digital resource to share?

Contributions and suggestions are welcome!

Before submitting a resource, please make sure it:

- Provides genuine value to developers, learners, creators, or the wider community.
- Includes a working link to the original source.
- Clearly identifies whether it is free, freemium, or paid, when known.
- Includes a short, accurate description.
- Respects the original creator's copyright, licensing terms, and distribution rules.
- Does not promote malware, scams, pirated content, or misleading offers.

### How to Contribute

1. Fork this repository.
2. Add your resource to the appropriate category or suggest a new category.
3. Include its name, description, original URL, and known pricing information.
4. Submit a pull request for review.

You can also open an issue to suggest a resource or report a broken link.

## ⚠️ Disclaimer

This repository is a resource directory intended for educational, informational, and discovery purposes.

- Resources belong to their respective creators, owners, or publishers.
- Links direct users to external websites and services that may have their own terms, privacy policies, and pricing.
- Listing a paid resource does not mean it is free, endorsed, or officially affiliated with this repository.
- Always review the applicable license before using, modifying, redistributing, or using a resource commercially.
- If you are a resource owner and believe a listing infringes your rights, please open an issue or contact me so it can be reviewed.
